# ShareDoc v3

Версия проекта, в которой шаблоны стали самодостаточными:
- постоянные сведения о ФГАНУ «ЦИТиС» оставлены внутри DOCX-шаблонов;
- из БД подставляются только данные организации, контактного лица и параметры курса;
- генерация документа зависит от `template_code`;
- рассылка писем не участвует в основном сценарии.

## Структура

- `src/sharedoc/config.py` — настройки БД и путей;
- `src/sharedoc/db.py` — инициализация схемы и сбор контекста документа;
- `src/sharedoc/main.py` — CLI;
- `src/sharedoc/sql/sharedoc_schema.sql` — схема PostgreSQL;
- `src/sharedoc/sql/seed_demo.sql` — демонстрационные данные;
- `src/sharedoc/template/*.docx` — 3 шаблона с постоянным текстом ФГАНУ «ЦИТиС».

## Установка

```bash
pip install psycopg2-binary docxtpl python-dotenv
```

## Переменные окружения

```env
DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=ClientBase
DB_USER=postgres
DB_PASSWORD=admin
```

## Команды

```bash
python -m sharedoc init-db
python -m sharedoc seed-demo
python -m sharedoc info 1
python -m sharedoc generate 1
```

## Что хранится в БД
- организации-клиенты;
- контактные лица;
- параметры конкретных запусков курсов;
- очередь/описание документов на генерацию.

## Что хранится в шаблонах
- реквизиты и постоянные сведения ФГАНУ «ЦИТиС»;
- подписант и контакты для связи;
- постоянные фрагменты текста каждого письма.

## Примечание по шаблонам
В старой экспериментальной версии некоторые поля `org_full`, `org_short`, `email1` фактически использовались как поля адресата, хотя по названию выглядели как данные исполнителя. В этой версии переменные шаблонов переименованы, чтобы отделить данные клиента от постоянного текста шаблона.
